ANOA SMART HOSPITAL AIoT — DEMO WEBSITE
========================================

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka file index.html dengan browser Chrome, Edge, atau Firefox.
3. Tidak perlu instalasi server, database, maupun koneksi internet.

Fitur:
- Dashboard petugas rumah sakit.
- Simulasi antrean (panggil nomor berikutnya).
- Ubah status kehadiran dokter.
- Monitoring sensor tanda vital (nilai simulasi).
- Transparansi kuota BPJS (data contoh).
- Rancangan integrasi RME / SATUSEHAT.
- Portal pasien: daftar online, dokter, antrean, BPJS.
- Perubahan antrean dan dokter tercermin di portal pasien.

Palet identitas: biru langit #2C99D6, putih #F8FAFC, merah scarlet #EB2E33.
Dirancang desktop dan perangkat mobile.

PENTING:
Ini hanya prototipe interaktif untuk esai ANOA dan presentasi inovasi.
Tidak terhubung ke rumah sakit, BPJS, SATUSEHAT, maupun sensor IoT sesungguhnya.
Semua angka, pasien, dokter, dan statistik pada dashboard adalah simulasi.
Pendaftaran hanya berlangsung di browser lokal, tidak dikirim atau disimpan ke server.
Tidak dimaksudkan untuk keputusan klinis atau layanan kesehatan langsung.
